# VK Equipment Rental System

Система проката снаряжения для сообщества ВКонтакте.

## Описание

Веб-приложение для управления прокатом туристического снаряжения. Позволяет пользователям просматривать доступное снаряжение, создавать заявки на прокат, а администраторам - управлять снаряжением, пользователями и заявками.

## Функциональность

### Для пользователей:
- Регистрация и авторизация через VK ID
- Просмотр каталога снаряжения
- Создание заявок на прокат
- Просмотр истории своих заявок
- Отслеживание статуса заявок

### Для администраторов:
- Управление пользователями
- Управление снаряжением (добавление, редактирование, удаление)
- Обработка заявок (одобрение, отклонение, выдача, возврат)
- Просмотр всех заявок и статистики

## Технологии

### Frontend:
- React 18
- Material-UI (MUI)
- Axios для HTTP запросов
- Date-fns для работы с датами

### Backend:
- Node.js
- Express.js
- MySQL
- JWT для аутентификации
- bcryptjs для хеширования паролей
